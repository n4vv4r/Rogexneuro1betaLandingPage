# NAVI 6.6 para dummies

Imagina un mecanico que tambien sabe poner articulos y corregir un
tachon.

1. Tu escribes «ola kien eres».
2. El corrector marca el tachon y supone «hola quien eres».
3. Te lo dice. No finge que escribiste bien.
4. Responde con oraciones: articulo + verbo + conector.
5. Si pides «conjuga escribir», saca la tabla. Si pides Kubernetes:
   DESCONOCIDO.

No es ChatGPT con un tema oscuro. Es 6.5 con gramatica y una TUI de
colores (cajas, spinner, el texto se escribe solo).
