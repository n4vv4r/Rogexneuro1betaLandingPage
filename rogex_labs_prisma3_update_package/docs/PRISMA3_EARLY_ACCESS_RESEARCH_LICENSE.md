# PRISMA 3 Early Access Research License

This document defines the public-facing commercial framing for PRISMA 3 Early Access.

## Product

**PRISMA 3 Research Core — Early Access Research License**

Suggested price: **249 €**

This is access to an experimental EEG research software codebase, not a finished clinical product.

## Includes

- PRISMA 3 codebase for local research use.
- Demo data and reproducibility assets.
- Streamlit interface (`streamlit run run_app.py`).
- CLI dataset analysis tools.
- Initial ds007358 EC/EO validation pipeline.
- Subject-normalized LOSO and personalized intra-subject evaluation modes.
- Documentation and scientific limits.
- Permission to adapt local code for research workflows, subject to license terms.

## Does not include

- Clinical use.
- Diagnostic use.
- Medical claims.
- Guaranteed accuracy on external datasets.
- Universal BIDS compatibility.
- Redistribution, resale, mirroring or public leaking.
- Automatic public download.

## Correct sales wording

> PRISMA 3 Early Access Research License gives researchers access to an experimental EEG analysis codebase with an initial real-world validation on ds007358 EC/EO. The current pipeline includes raw LOSO evaluation, subject-normalized LOSO evaluation, personalized intra-subject modeling, alpha-blocking sanity checks for EC/EO, and editable BIDS-oriented dataset analysis code.

> PRISMA 3 is early-access research software, not a clinical or diagnostic tool. Multi-dataset compatibility is under active development, and users may need to adapt dataset loaders or adapters for their own EEG data.

## Access model

Recommended commercial flow:

1. User submits access request.
2. Use case and identity are manually reviewed.
3. License terms are accepted.
4. Payment instructions are sent after approval.
5. Personalized encrypted ZIP is delivered.
6. Password is sent separately.
7. Delivery manifest / buyer record is stored internally.

## Boundary sentence

PRISMA 3 is experimental research software. It is not a medical device and does not diagnose, treat, cure or predict disease.
